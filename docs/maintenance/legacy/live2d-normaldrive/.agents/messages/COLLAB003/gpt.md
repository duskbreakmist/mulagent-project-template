## E 的关键修正

- 项目共享文件汇总者与每个 task 的 integrator 区分，按具体文件／区段委派；“共同负责人”不能授权两人同时改同一共享文件。
- 用户已指定或已预授权的备用人可按原授权接班，不重复询问；缺少授权不能因额度／超时／沉默接管。
- 正常退出留交接，异常退出从此前检查点与 Git 恢复。不能要求耗尽额度的旧执行者必须再写最终交接才准恢复。
- 不设默认 24 小时。空窗冻结争议共享写入，已授权且无冲突的独占工作仍可继续。
- 交付验收与协调状态分开；没有继任建议不把已完成任务标 blocked。保存不同意见和处理理由，不能虚构共识。
