# ADR-001：任务中心的单主目录协作

日期：2026-09-30。状态：本工程采用；其他 Agent 尚未确认读取。

## 问题

作者目录能够避免研究报告互相覆盖，却无法描述任务所有权、接手状态与公共代码整合。各 worktree 也不会实时同步任务文件；共享接龙表并发写仍会冲突。

## 决定

保留作者研究目录，任务状态统一到 .agents/tasks。AGENTS 是稳定入口，登记单独维护。指定本机主协作目录，integrator 串行维护任务表和共享索引；worker 写自己命名的消息／交接和限定范围产出。

并行源码编辑使用 worktree；同 checkout 的 Git 操作串行。提供自包含单文件 AGENTS 模板，初始化独占锁和独占发布，结构标记最后写入。初始化不等于登记或接受任务。

## 影响与限制

协议靠实际遵守，不提供权限隔离、自动通信或跨机器状态事务。若跨机器并发协调成为需求，升级到真实状态／消息服务；不能继续把每个 clone 的 task 当实时全局状态。

提交的 Agent／Task／Role 仅追踪来源，不认证身份。保留现有 Git 身份，不配置未经授权的厂商伪身份。

操作细节见 ../../.agents/PROTOCOL.md；依据和被修正观点见 ../../gpt/research/multi-agent-protocol-review.md。

后续用户要求降低每个 Agent 的阅读负担。可复制版本改为 gpt/project_templateA 多文件骨架，短 AGENTS 只索引核心规则，其余格式／Git 指南／维护手册按需读。模板已展开，无需初始化标记；独立 Python 仅作可选只读完整性检查。本工程原有 v1 初始化器继续维护既有结构，避免把新模板安装行为与当前工程修复流程混用。

## 协作模式更新（2026-10-01）

增加 serial / collaborative / independent_compare，与进度 status 分开。未指定模式的新任务由 integrator 使用可用交互提问工具请求用户选择；其余实例读取共享任务记录，避免重复询问。独立对照同任务多候选，各写任务／轮次／Agent 子目录，固定输入后独立提交，评审阶段才汇总，原始结果保留；正式实现各用 worktree。提示词不保证弹窗或盲测隔离，客户端和实际执行另需验证。
