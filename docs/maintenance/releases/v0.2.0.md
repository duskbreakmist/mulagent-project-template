# v0.2.0 — 多 Agent 工程协作模板

本版将协作协议、Git 安装／升级工具和母模板维护工程整理为可固定版本使用的协作基础，适用于有人监督的单人或多 Agent 业务开发。

## 主要变化

- 业务 README 集中六项工程约定，AGENTS 与 task 格式引用实际规范和验收命令。
- 安装器保护业务状态与五个种子文件，三方合并有冲突时整轮不写原文件，保留人工审查候选。
- 新增 update --ref，显式切换已有分支／标签；预览、无效引用和未应用冲突不提前改变基线。
- 检查器验证核心锚点、UTF-8、受管理 Python 语法、本地链接及已填写任务状态；母仓库另有 --maintenance 检查。
- 本地模板来源记录绝对路径，update --source 支持恢复或显式切换来源。
- Apache-2.0 原文与来源说明随默认分发集交付：由33项增至35项。许可位于 .agents/licenses/，业务根 LICENSE 保持自有内容。
- 可选工作台提供登记、认领、消息和接力看板；不默认安装，真实客户端启动与额度适配仍须单独验证。

## 安装和升级

需要 Python 3.9+ 和 Git。Windows／Ubuntu CI 使用 Python 3.13；本版未重新验证 Python 3.9 或 macOS。

在空业务工程目录执行，同级工具目录须尚不存在：

```powershell
git clone --branch v0.2.0 --depth 1 https://github.com/duskbreakmist/mulagent-project-template.git ../agent-template-tools
python ../agent-template-tools/tools/template_manager.py init --root . --ref v0.2.0 --commit
python tools/check_template.py --root .
```

已有工程先保存业务改动、获取本版同级工具，然后预览／应用：

```powershell
python ../agent-template-tools/tools/template_manager.py update --root . --ref v0.2.0 --check
python ../agent-template-tools/tools/template_manager.py update --root . --ref v0.2.0
python tools/check_template.py --root .
```

旧 updater 不支持 --ref 时用同级工具。冲突按 docs/template-usage.md 审查后 apply；运行业务测试，提交规则更新和 .agents/template-state.json。业务 README 等五个种子保持原样，工程约定需自行补齐。

## 验证和边界

发布验证结果记录在 [REL001-CODEX](../tasks/REL001-CODEX.md)。TEMPLATE_OK 不代表业务功能、跨文件状态同步或上线验收；业务工程定义自己的测试、CI 与部署。真实客户端无人值守调度、额度轮换和生产部署未验收。

GitHub 自动生成的源码归档是完整母仓库，包含维护历史和测试；安装器仅将 manifest 的35项通用文件装入业务工程。旧标签保持不变。
