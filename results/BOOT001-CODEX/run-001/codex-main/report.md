# codex-main 自举判断首稿

结论：当前项目已经能在外部 AI 和人工授权参与下，用自身协作规则维护自身，也能由已安装副本继续生成协议骨架。完整开发仓库的再生产需要 Git clone 等外部动作；无人值守的真实多 AI 自我改进闭环尚未得到实现与验收证据。

## 定义与判断

| “自举”的含义 | 判断 | 证据与条件 |
| --- | --- | --- |
| 用本项目协议组织本项目的开发／审查／记录 | 可以，人参与的自身维护 | AGENTS.md、.agents/PROTOCOL.md；docs/maintenance/README.md:3–5、19–32 将实际维护 task 与分发种子分开。既有 Git 维护提交和本轮任务表明协议确实用于本仓库。 |
| 从自身 Git 源码安装新工程，并管理后续升级 | 可以 | tools/template_manager.py:110–140、196–225、410–434；初始化写入包含自身安装器的 33 项清单，保存 source/ref/revision/文件哈希；update 使用该基线生成计划。 |
| 由第一代分发副本生成第二代分发副本 | 可以，已做离线实测 | reproduce.py 使用第一代已安装管理器和第一代已提交 Git 快照生成第二代，两代 checker 成功、独立 Git 干净、无 remote。只证明当前未定制骨架的两代传播。 |
| 普通分发副本拥有母仓库完整的开发／测试／工作台能力 | 当前默认安装不具备 | .agents/template_manifest.json:4–38 未包含 tests、.github、docs/maintenance、工作台与 relay；本轮两代副本均确认这些路径不存在。这是分发设计边界，不能仅据此判定整个母仓库无法自举。 |
| 自动启动真实 AI、额度接力、开发→测试→修复→再验收 | 有基础接口，完整闭环未证明 | tools/agent_workbench.py:323–356 实现版本关联与开发／测试角色区分；565–645 监督注册的前台命令。没有 command 时返回 manual；真实供应商适配器不在本仓库。当前单次 dispatch 不会自动调度完整任务图或凭测试反馈生成修复。 |
| 脱离 Python、Git、外部模型和授权仍自行运行 | 不支持 | 安装器是 Python 程序且依赖 Git；协议文件本身不能执行任务，工作台也不含模型推理实现。 |

## 实际验证

基线为 `8d2645f80f43df4932515f5b6650a05e53410f5b`。Python 3.13.8，Windows PowerShell。完整实验结果保存在 [verification.json](verification.json)。

```powershell
python tools/check_template.py --root .
python results/BOOT001-CODEX/run-001/codex-main/reproduce.py
```

母仓库 checker 返回 `TEMPLATE_OK files=33`。实验两代都返回同样结果，且安装之后调用各自 update --check 得到 `changes=0 conflicts=0 protected=5 removed_upstream=0`。实验使用本机已有真实 Git 身份，仅临时配置到隔离副本；临时目录已由脚本清理，母仓库 Git 配置与源码未变。

现有完整 unittest 已启动；沙箱内两次均在临时目录创建 `.agents` 时遇到 WinError 5，换 TEMP 路径仍然失败。沙箱外重跑经自动审批获准，首稿提交时仍在执行；最终结果由 comparison 记录，首稿不提前认定通过。两代实验也是沙箱外运行。权限失败属于本轮环境证据，不能据此宣称业务断言失败。

## 能力边界与建议

1. 对当前问题，最准确的表述是“已实现人参与的协作自举和模板骨架再生产”。目前可以由 AI 在本仓库提出修改、按本协议审查、运行测试并保存版本。
2. 新工程若要成为完整模板开发者，应取得母仓库完整源码／测试／维护入口，明确维护身份和源；不能将默认 init 当作完整开发套件复制。普通业务工程继续消费协议即可，无须默认扩大清单。
3. 若把已经产生真实登记、task 和定制规则的业务副本用作新来源，init 会按该源 manifest 复制种子。当前两代实测只用空白种子，没有验证定制业务副本的自动去状态／通用化。因此不建议未经核查把任意业务仓库当作通用母模板。
4. 无人值守自举还需要真实客户端适配、监督器持续调度任务依赖与失败重试、将测试失败送回修复任务、源码／worktree／版本整合、停写确认和人工介入。当前已有部分状态与接口，不能写成全部缺失；这些也没有在本轮真实外部 AI 端到端验收。

## 独立性

本稿写入前未读取本轮 audit-a／audit-b 或其他自举候选。共享历史与源码相同；两个子 Agent 属于当前工具内部会话，模型版本未独立确认，不能称为跨厂商盲测。调查期间仅收到接受回执与环境限制消息。本轮未改变模板实现，也未启动其他桌面 AI 客户端。
